## [0.1.0] - 2025-10-18
- Initial public release of HANGMAN — a lightweight, terminal-based Hangman game written in Python.
- Highlights:
  - Playable terminal game with ASCII hangman art
  - Randomized word list from `words.txt`
  - Input validation and replay support
  - Cross-platform: macOS, Windows, Linux (requires Python 3.7+)
- How to run:
  - Ensure Python 3.7+ is installed
  - From the project root run: `python3 main.py`
- Known issues / limitations:
  - Words list must remain a JSON array in `words.txt`
  - Single-character, lowercase guesses expected
  - No automated tests included in this release
- Contact / permissions:
  - For permission requests (commercial use, redistribution, or public use), open an issue using the “Permission request” template or contact the author via GitHub.

# Contributing

Thanks for your interest in contributing to HANGMAN.

How to contribute

1. Fork the repository.
2. Create a branch for your change: `git checkout -b feature/my-change`.
3. Make changes and test locally: `python3 main.py`.
4. Commit and push to your fork.
5. Open a pull request describing your change.

Guidelines

- Keep changes small and focused.
- Include tests or manual verification steps for new behavior.
- Be respectful and follow the code of conduct.

Contact / Permissions

If you need permission for commercial or public use, open an issue describing your use case and contact details. The project owner will review and respond.
